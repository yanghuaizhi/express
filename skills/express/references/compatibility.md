# 与其他技能共存

Express 提供会话与文档共同的表达标准。它独立可用，也可以在研究、编码、产品文档或稿件编辑任务中持续应用。它不是这些任务的替代流程。

## 只走一套主要流程

用户已指定其他 Skill，或当前任务已有合适的专项流程时，沿用该流程。Express 只提供本次有关的表达与读者使用检查；不要把同一稿件自动生成两遍、重新审阅两遍。

没有其他写作 Skill 时，直接用模型能力完成用户要求，并应用共同原则。不要为使用 Express 要求用户安装 Waza 或其他插件。

## Waza Write

Write 的范围包含中文及英文稿件、作者语气、长文结构、文档审阅、发布文案与本地化。Express 不把这些能力复制成另一套并行流程，也不将它描述为仅能逐句润色。

日常对话的表达规则持续适用。需要专项稿件编辑时按 Write 的适用流程处理；用户指出当前回答没讲清楚时，Express 直接诊断并修正，不自动把任务转给 Write 重写。

两者都强调保真与清楚，原则存在重合。发生语气、标点、emoji 或交付形式冲突时，依据当前用户要求和项目约定选择，不强行拼接两种风格。必要的事实、条件与承诺强度不能因任何风格偏好而改变。

保留上游安装，不修改插件缓存，不锁定或复制它的内部路径。上游更新后的共存效果需按实际相关任务核对；Express 不承诺对所有第三方版本自动兼容。
